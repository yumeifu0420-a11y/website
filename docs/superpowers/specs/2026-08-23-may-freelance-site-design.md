# May Freelancer Website Design

## 目标

为付玉梅（May / 余寐）建立与 job-workbench 完全分开的客户向个人站。访问者在 3 秒内应理解她承接商业品牌内容、人物特稿、城市文化写作、AI 内容研究、跨文化文书与产业科技内容，并可直接通过邮件联系。

## 内容边界

- 只使用现有经历证据表、公开作品链接、成刊 PDF、联合国项目材料和 Retell 研究数据。
- 公开案例必须区分作者、联合作者、编辑或机构项目；职责不清、无证据的客户成果不作为核心证明。
- 不展示电话、内部客户数据、签证、证件、合同或其他敏感材料。

## 页面结构

1. Hero：人物定位、三类承接能力、联系 CTA、原创流动线稿。
2. 作品集河流：六条客户可理解的合作路径，每一条同时呈现可合作内容和真实作品证据。
3. 代表项目：商业品牌内容、人物与公共议题、城市人文写作、AI 模型测评与 Retell、跨文化文书、产业与科技调查。
4. 方法：研究—采访—结构—编辑—质量控制的可解释流程。
5. 关于与联系：真实照片、署名关系、中文/英文支持边界、邮件和 LinkedIn。

## 交互与验证

使用语义链接、键盘可见焦点、锚点导航、轻量滚动显现和 reduced-motion。桌面与移动端必须无横向溢出；全部公开链接和本地 PDF 必须可访问。
